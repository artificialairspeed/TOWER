DATA STRUCTURE
================================================================================

OLD (Flat):
  DeploymentFormData {
    changeItems: ChangeItem[]      [1-999 items, flat]
    impactItems: ImpactItem[]      [1-100 items, flat, no association]
  }

NEW (Hierarchical):
  DeploymentFormData {
    changeItemsWithImpacts: ChangeItemWithImpacts[1-999] {
      id: string
      jiraNumber: string             [1-50 chars]
      description: string            [1-500 chars]
      impacts: ImpactItem[0-100] {
        id: string
        text: string               [1-500 chars]
      }
    }
    changeItems: []                [legacy, empty for new forms]
    impactItems: []                [legacy, empty for new forms]
  }
