### 2. useMemo for Expensive Computations

#### DeploymentTitleDisplay - Title Generation

**File:** `src/components/DeploymentTitleDisplay.tsx`

The deployment title is generated by combining multiple form fields:
- Application name
- Change number
- Release version
- Environment

**Implementation:**

```typescript
const computedTitle = useMemo(() => {
  if (!data.application) return '';
  
  return [
    data.application.name,
    data.changeNumber,
    data.releaseVersion,
    `[${data.environment}]`
  ].filter(Boolean).join(' - ');
}, [data.application, data.changeNumber, data.releaseVersion, data.environment]);
```

**Benefits:**
- Title computation only runs when dependencies change
- Avoids expensive string concatenation on every render
- Improves performance for frequently re-rendering parent components

### 4. Lazy Loading of Artifact Libraries

Expensive libraries are loaded only when needed, reducing initial bundle size and load time.

#### html2pdf.js Lazy Loading

**File:** `src/utils/artifactGeneration.ts`

```typescript
async function loadHtml2PDF() {
  if (html2PDF) return html2PDF;
  
  const module = await import('html2pdf.js');
  html2PDF = module.default || module;
  return html2PDF;
}
```

#### html-to-image Lazy Loading

**File:** `src/utils/artifactGeneration.ts`

```typescript
async function loadHtml2Image() {
  if (html2Image) return html2Image;
  
  const module = await import('html-to-image');
  html2Image = module;
  return html2Image;
}
```

**Usage Pattern:**

```typescript
async function generatePDF(htmlString: string, filename: string): Promise<void> {
  const html2PDF = await loadHtml2PDF();
  // Use html2PDF...
}

async function generatePNG(htmlString: string): Promise<string> {
  const html2Image = await loadHtml2Image();
  // Use html2Image...
}
```

**Benefits:**
- Reduces initial JavaScript bundle size
- Libraries loaded on-demand only when user exports
- Improves Time to Interactive (TTI) metric
- Faster initial page load

## Best Practices Applied

1. **Memoization with Purpose**
   - React.memo applied only to components that receive many re-renders
   - Callbacks memoized where they're passed to memoized children

2. **Dependency Arrays**
   - useCallback dependencies carefully selected
   - Avoid unnecessary array reconstructions

3. **Key Props for Lists**
   - Used stable `id` as key for list items
   - Prevents reordering issues and ensures proper memoization

4. **Lazy Loading**
   - Libraries loaded on first use
   - Caching to prevent duplicate loads
   - Async/await pattern for clean error handling
